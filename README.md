# frukon

CloudStream için Türkçe film, dizi ve anime eklentileri.

## Kuruluma ekle

CloudStream uygulamasında **Ayarlar → Extensions → Depo Ekle (+)** yolunu izleyip aşağıdaki URL'yi yapıştır:

```
https://raw.githubusercontent.com/faruktunc/frukon/builds/repo.json
```

## Eklentiler

| Eklenti | İçerik | Durum |
|---|---|---|
| DiziPal | Yabancı dizi ve film (arama şu an site kaynaklı olarak devre dışı) | Beta |
| DizipalExtended | Yabancı dizi, film ve anime (dizipal.bid aynası) | Beta |
| DiziWatch | Yabancı dizi ve anime | Beta |
| FilmMakinesi | Film ve dizi | Beta |
| HDFilmCehennemi | HD film ve dizi | Beta |
